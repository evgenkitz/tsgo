## Внедрение

https://github.com/microsoft/typescript-go/issues/3367

## Использование

1. читается скриптом `_scripts/generate-go-ast.ts`
2. на основе автоматически создаётся файл `internal/ast/ast_generated.go` с Go-структурами для всех узлов AST

## Структура ast.json

Файл содержит два корневых раздела: **`kinds`** и **`nodes`/`bases`**

**Секция `kinds`** — перечень всех `SyntaxKind`-значений в правильном порядке. Элементы могут быть строкой (имя kind) или объектом `{ "name": "...", "comment": "..." }` для аннотированных значений. Порядок важен — он определяет числовые константы в Go. Включает:

- Литеральные токены (`NumericLiteral`, `StringLiteral`, `BigIntLiteral`…)
- Пунктуацию (`OpenBraceToken`, `DotToken`, `EqualsToken`…)
- Ключевые слова (`BreakKeyword`, `ClassKeyword`, `IfKeyword`…)
- Строгие зарезервированные слова (`LetKeyword`, `StaticKeyword`…)
- Контекстуальные ключевые слова (`AsyncKeyword`, `ReadonlyKeyword`, `AbstractKeyword`…)
- Синтаксические узлы (`QualifiedName`, `TypeParameter`, `Parameter`, `BinaryExpression`…)

**Секция `bases`** — базовые типы/трейты, которые могут быть вложены в узлы. Каждый base соответствует Go-структуре с embedding. Имя Go-структуры по умолчанию — `Capitalize(key)+'Base'`; поле `go` задаётся только если имя отличается.

**Секция `nodes`** — список конкретных типов узлов. Для каждого узла описываются:

- `kind` — соответствующий `SyntaxKind`
- `bases` — список base-типов для embedding
- `fields` — поля узла: имя, тип (`*Node`, `*NodeList`, `string`, etc.), опциональность
- дополнительные метаданные (например, является ли поле дочерним узлом для обхода)
